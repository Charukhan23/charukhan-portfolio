My Projects

FINAL YEAR PROJECT

Smart Charging System for Electric Vehicles Using Wireless Power Transfer

This is my final year project. The problem is simple: EV charging has issues with wires, waiting time and parking. My solution is wireless charging. When a car is parked, it starts charging automatically. It also supports charging while travelling.

I built a real-time web dashboard to monitor charging data, battery level, parking mode and travel mode. This project was selected and I presented a paper at the International Conference RATSTEm-2026.

Technologies: Embedded C, Python, IoT, Wireless Power Transfer, Real-Time Monitoring

AI / PYTHON / STREAMLIT

AI-Integrated Platform for Smart Agriculture

A complete platform for farmers. It predicts crop yield for the season. If a farmer uploads a leaf photo, it detects leaf disease. It uses NDVI-based analysis to check if the plant is healthy. It also includes an e-marketplace module where farmers can sell directly.

Technologies: Python, Streamlit, AI / ML, NDVI

Impact: My aim was to bring technology to farmers in a simple and useful way.

SMART INDIA HACKATHON - SIH

AI-Powered Crop Health Monitoring

A project built for Smart India Hackathon. Instead of a normal camera, it uses multispectral / hyperspectral imaging to scan crops. The data goes to a cloud-based analytics pipeline, which gives early warnings about pest risk and soil risk.

Technologies: AI, Cloud, Data Analytics, Imaging

Learning: I learned to work in a team and build under time pressure in a hackathon.

EMBEDDED / PLC

Modern Touch-Sensor RGB LED Smart Table

A smart table that changes light when you touch it. I designed control firmware with PLC-based touch sensor input and RGB LED logic for interactive lighting response.

Technologies: PLC, Embedded, Touch Sensor, RGB LED

IOT / RASPBERRY PI

Smart Home Lighting Automation

Home lighting that turns off automatically when no one is in the room, and turns on when someone enters. It uses sensor-based triggers and remote monitoring through a mini network.

Technologies: Raspberry Pi, IoT, Sensors
